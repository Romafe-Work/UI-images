# Mobile

Os ecrãs do telemóvel e do PDA. Ainda não há nenhum.

Para começar: copiar `../erp/index.html` para aqui, mudar o `<html>` para
`data-app="mobile" data-marca="…" data-tela="480x800"` (o mapa e o editor
leem o tamanho daí), e escrever a base (`<template data-base="…">`) antes do
primeiro ecrã. Depois `python3 ../catalogo.py`.
